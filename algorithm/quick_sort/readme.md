# 快速排序
 - 数组排序
   - 冒泡 两两相邻位置 比较
   - 选择排序 选择最小的元素 放到第一个位置
   - 插入排序 从当前位置开始 与前面的元素比较 如果小于前面的元素 则交换位置
   O(n^2)

## 快速排序 O(nlogn)
 - pivot 基准值
 - 比他小的元素 放到左边
 - 比他大的元素 放到右边
 - 递归排序 左边和右边的数组 重复以上步骤

 快排(quick sort) 是一种基于**分治策略**的排序算法
 分而治之

## 递归 分治的区别
 - 递归是代码的实现方式（函数调用自己）
   自顶向下 缩小问题的规模
 - 分治是一种算法设计策略，绝大多数用递归实现
   分 + 治 + 合 三步
   分 将问题分解成更小的问题
   治 解决每个小问题
   合 合并小问题的结果

   左边 pivot 右边

   相等元素相对位置颠倒，体现快排不稳定

## 总结
 - 快的原因
   pivot 基准值 (Ologn) + 原地交换 O(n) 双指针
 - 不稳定
   相等元素相对位置颠倒，体现快排不稳定
 - 分治策略
