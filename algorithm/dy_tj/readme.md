## 第一步 多模态解构
 - 多模态是llm 的主要发展热点
   一段视频，向量化存储
 1. **视觉特征** 逐帧提取
    vision transformer(llm 的底层)
    以帧为单位，提取视频的视觉特征
    能认出是一只猫，一个程序员在写代码，一个寝室围绕着看世界杯
    甚至可以通过画吗的色彩，光影判断视频的情绪基调，温柔治愈、还是冷酷硬核
    抖音视频数据量最大
    机器学习和大数据训练
 2. **音频特征**
    musicly 训练
    通过ASR 技术，将音频转换为文本
    文本NLP 自然语言处理，语言分析
    声音的大小，情绪
    最终形成一个512 维的向量

## 推荐漏斗
 - 第一步的输入 每个视频512维的向量
   这一步的输出
   ### 双塔模型广撒网
   千人千面
   1000万条视频
   1000条
   - 第一步 召回：双塔模型
     向量的点积运算，cosin 夹角，把相关的1000条视频筛选出来
   - 第二步 初 (粗) 排
     用相对轻量的机器学习模型，算一些粗的内部特征
     从上面的1000条，筛选为300条
   - 第三步 精排
     预测点不点击，完播的概率，点赞、评论、分享的概率
     score = w1.点击 * w2.完播 * w3.点赞 * w4.评论 * w5.分享
   - 重排
     如果前十名都是你喜欢看的AI视频，重排机制会强制打散。
     每几个硬核视频，强制加入一个跳舞视频，防止产生疲劳。
     Explore 探索 Exploit 利用
     80% 已知爱好 20% 探索潜在兴趣。
     野外求生，多停留几秒，一个全新的兴趣被记录
