## 多种解法
 - 俩重循环去重
 - indexOf 方法去重
   - 1.数组的下标和原数组的 index 比较
   - 2.当前项和res 数组里比较-1，说明当前项不存在，添加到res 数组里
 - 先排序，相邻项比较
     时间复杂度 O(nlogN)
     缺点是数组的稳定性被破坏了
 - hash table | 对象的字面量属性去重
     数据结构的一种
     优点是O(n)
     用空间换时间 (缺点)
     数据结构：解决特定问题的数据存储结构和特定行为
 - 专有数据结构 
     es6 新增的数据结构
     Map 映射关系
     Set 集合
