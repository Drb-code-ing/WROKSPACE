# 决策模型

## Jev 到底是什么？

人的思考方式分成了两套系统：
系统一：负责快速判断，看到前面有东西飞过来，我们会本能的躲开。
       看到一个人的表情，我们很快能判断他是否开心/生气。
系统二：负责的是慢思考，做一套负责的数学题，分析一份商业计划，或者做一款游戏，
       都需要投入更多的注意。

过去几年，大模型的发展主要在不断加强系统二。模型要学会去理解复杂问题、展开梳理、调用工具、
生成一段完整的答案。
而TypeSafe 提出问题就是一个AI 系统里的每一步都需要这么样的认真思考吗？

程序需要的不是一篇文章，而是一个判断，Jev

TypeSafe 把他叫做 System One Model

借鉴了思考，快与慢的概念。把Jev 理解成一个专门去给程序使用的决策模型。

例子：
我们的东西一个星期还没到，现在不想要了。
客服系统现在可能还不需要模型去写回复，而是需要搞清楚几件事：
这个用户是在查物流，还是准备退款，情绪是不是激烈，要不要转给人工客服？

Jev 根据动态的用户评论，从开发者给定的选项里做选择，并且告诉程序每个答案多大概率。
程序拿到结果以后，就可以进行执行对应的流程。

System One Model  负责判断
System Two Model(llm)  负责写答案

## 它的优势？
第一优势就是快，一次决策70-500ms。对于浏览器的操作，实时审核Agent 路由，
这类连续决策任务，都需要快速响应

第二个优势是便宜，是gpt 的1/10。

## 判断层到底是什么？
判断层是代码和大模型之间，负责专门“做选择”的那一层。

大模型相当于是问答题，它的输出是一大堆文本，可能需要你从中提炼答案。
判断层则是一张答题卡，选项是你事先印好的，只能在选项里涂，每个选项旁边还标着几成把握。

所以，判断层接口至少做到几点：
1. 答案范围由你来定，返回代码能直接用的值
2. 每个答案都带着概率，让代码决定哪些自动处理，哪些交给人工

给Jev 一份输入状态state 就是要判断的材料，再给他一组问题，问题分三类：
1. 多选一 Choice
2. 等级打分 Score
3. 是非判断 Noul

放到电商里，这个商品是属于服饰、数码、还是家居

## 判断层放在系统的哪里？
有了判断层，AI 应用就形成了三层分工，代码负责计算，jev 负责判断，大模型负责推理和创做。

拿重复扣款来说，用户发来一句“同一笔订单被扣了两次钱，麻烦退一下。”
代码先查扣款记录、核对金额和退款时效；在把用户消息、扣款记录和退款政策交给JEV，
一次问清楚：用户是否申请退款，扣款是不是真的重复，政策支不支持。
代码根据jev 答案决定退款，最后才让大模型写一段得体的回复。
Jev 拿不准时，再转给人工客服

我们发现，流程始终由代码掌控。Jev 只回答代码问它的问题，大模型只在需要文字时才调用。

## Jev 判断层已经成为AI 应用基础设施

数据库是web 时代的基础设施。
jev 要成为基础设施，三个特征：接口标准(SQL)、便宜到不假思索的调用、行为可预期

可以用在Agentic RAG 中代替很多传统的判断层
