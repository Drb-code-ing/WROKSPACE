#### 如何使用TypeScript 的模版字面量类型(Template Literal Types) 约束AI 返回的特点格式字符串(如日期、ID)？

**场景**
PromptTemplate 格式化场景

> 模版字面量类型就像给字符串定了个“模具”。我们可以用${string} ${number} 等占位符拼出想要的格式，只有一样的字符串才能通过类型检测，专门用来约束日期、ID 等固定格式的字符串

它的好处是让非法格式在编译阶段就被发现，也可以结合infer 做类型层面的模式提取
infer 是TypeScript 条件类型里的一个关键字，作用是在类型层面做 模式匹配+类型提取

#### 请用TypeScript 实现一个”类型安全的Prompt 模版解析器“，要求支持变量插值、类型检查、默认值、必填项等

Prompt 模版解析器：对带占位变量的Prompt 字符串做插值填充、效验变量类型、提供默认值、输出prompt

Langin PromptTemplate | ChatPromptTemplate

传变量时容易传错类型、漏传参数；类型安全就是TS 提前拦住，不让错误数据进入Prompt

这个需求在LLM/Agent 场景里常见：我们写Prompt 模版里埋变量，比如`你是一个{role}，请用{language}回答用户问题{question}`。如果传参漏了，传错了类型，prompt就错了，甚至人llm 输出异常。
类型安全Prompt 模版解析器就是用TS 泛型锁定

#### 在前端实现一个Agent 循环时，如何管理工具调用的异步执行、超时处理与结果合并？
- 前端还要实现Agent Loop?
  前端可做轻量的Agent 循环，用Promise 管理异步、超时、收集工具结果
  考的不只是Promise, async/await, Promise.all 等，不要一上来就说Promise.all（并行），await 串行，
  而是我们有真正设计一个**能稳定运行的Agent 执行引擎**

  结合一个具体场景来讲，“帮我查一个北京的天气，再推荐附近适合吃饭的餐厅，最后给我一个建议”。
  AI 先调用天气和搜索工具，再根据执行结果决定是否继续调用其他工具，最后整合信息给用户
  这个过程就是Agent Loop

- 讲清楚架构，再讲具体实现
  我会先把Agent 循环拆成几个阶段：模型决策、工具调用、结果收集、结果传回模型，以及判断是否结束。

第一，工具怎么执行？
如果两个工具互不依赖，就可以并行执行；如果两个工具有依赖关系，就只能串行执行。

第二，工具执行不了怎么办？
比如天气一直不返回，或者搜索服务报错，不能让整个Agent 卡住，设计超时、错误处理和必要的重试机制。

第三，执行完怎么合并结果？
不能只把几个Promise 结果拼起来，而是要保留每次工具调用的ID、执行状态和结果
按模型要求传回(message ToolMessage) 让模型准确知道每个工具对应的结果

最后，我还会设置最大循环次数、总执行时间和工具调用权限，避免Agent 无限循环

- 架构设计
1. 接收用户问题
   初始化对话、循环次数、总时间预算
2. 请求AI 模型，规划
   要不要调用工具
3. 效验并调度工具
   检查参数、权限、并发
