# FDE forward Deployed Engineer 前沿部署工程师

最近AI圈有个岗位很火，不是算法工程师，也不是agent工程师，而是FDE工程师。
前沿部署工程师
Soft Engineer(古法软件工程师 copilot 代码建议 人是主力 ai辅助)

-> Agent Engineer(智能体工程师 ai编程能力强 可靠的执行)

数据化 数据智能

AI 公司已经进入一个新的阶段，过去大家拼的事模型能力，谁参数更强，谁上下文更长(一次可以给llm的信息大小)，谁跑分更高(计算， 推理，编程...)，谁写代码更厉害，
现在是谁真正把 AI 落地在企业业务

企业买 AI 不是买一个API 也不是买token 企业要 **降本，提效，增长，风控**
是一个能真正嵌入到业务流程中，每天被员工使用，最后能产生业务结果的系统

FDE 更像是站在客户现场的一个AI工程负责人

工作内容：
 - 理解客户的业务流程，越垂直越好
 - 那些环节适合AI来改造
 - 把企业内部的数据，系统，工具连接起来
 - 搭建Agent 工作流，知识库，评测体系
 - 确保这些东西在生产环境跑起来
