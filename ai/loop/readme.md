# AI Loop

## Loop 循环
  一条推文迎来了700万人参观 开源大佬 别再给AI 写提示词，你应该去设计Loop
  Claude Code 作者也说 我也不写prompt 我也Loop

  - Loop 计算机最底层的技术之一
    Loop 包含三件事：
    - 从哪里开始 重复做什么 什么时候停
    一万行数据，要逐行检查，改格式，人工很久才能完成
    我们现在在用的所有AI 都是Loop 跑出来的 DeepSeek，Claude，Qwen ....
    训练底层都是一个逻辑
    
    拿一批数据给模型看，算它错了多少，调整参数，再来一轮。
    万亿次循环后，AI 就学会了对话和协作

    每天和AI 一问一答的过程，写Prompt 看结果 不满意 再改再来
    手动，AI 协作
    工作交给了AI 但是得盯着AI 干活。
    Loop 可以把我们抽离出来
    - complection
    - check
    循环往复 跟最终目标对比 退出

    优势，解放了人
    缺点 token大爆炸
