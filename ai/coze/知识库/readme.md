## 知识库
 - 海量的训练数据
 - 瓶颈是什么？
  - 过时的 最新的数据没有
  - 个人，企业私有数据没有
  如何给llm 提供它没有的知识呢？
  知识库是结构化存储领域知识、供AI查询调取以精准答疑推理的信息资源库。
