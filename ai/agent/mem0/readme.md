# Mem0 三路召回的长期记忆方案

长期记忆检索
知识库三路检索 向量 + 关键字 + 多跳，同时适用于长期记忆检索
psql + elastic search + neo4j 繁琐，Mem0 是一个更简单的方案。

三路召回的记忆挺麻烦的，mem0 是业内主流的Agent 长期记忆库，原生集成语义检索、BM25 检索、知识图谱检索三大能力，默认完成三路检索的融合打分与结果排序，完全契合我们的技术要求。

## 三种记忆

mem0 一共有三种记忆的作用范围

- 用户记忆 长期存储 跨会话端存在 user memory
  存着跟人走的长期信息
  姓名、爱好、偏好、城市
  绑定 userID
- 会话记忆 session memory
  绑定 userId + runId
  讨论这次要做什么、讨论到哪一步、临时目标等
  仅在当前会话有效
  当前任务
  session_id
- Agent 配置与记忆 agent memory
  绑定 agentId
  存的某个Agent 这是的设定：角色、语气、回答方式等
  旅行

  用户记忆管“这个人”，会话记忆管“这次聊什么” ，Agent 记忆管“这个助手是谁”
