# Agent 的对象存储方案

AI Agent 在跑业务的时候，时时刻刻都要读写各种文件。
不管是上传的文档，还是AI 自己生成的报表、视频图片
普通的本地文件夹根本扛不住海量文件的生产环境。

## OSS
Object Storage Service 对象存储服务
bucket 是一个对象存储空间，用于存储和管理对象。支持分布式和动态扩容
没有文件夹概念，所以文件都是以对象的形式存储的
叫对象存储 是因为它不以目录树或磁盘块来管理数据，而是把每个文件当成带唯一ID 和元数据的“对象”来存取

## 三类场景
- 存放 RAG 知识库源文件，给智能体提供数据源
- 保存 Agent 自动产出的报表、图表、运行日志
- 统一重复图片、音频、视频，支持多模态AI 处理任务

## MinIO
MinIO 是一个开源的对象存储系统，支持分布式和动态扩容
没有文件夹概念，所以文件都是以对象的形式存储的

直接用阿里云的 OSS 方便，但是要支付费用，而且企业内部资料也不希望上云
