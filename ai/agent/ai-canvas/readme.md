# ai-canvas

## 多模态Agent 图解

它支持图片、文本、语音、视频、文档表格这类多模态输入，核心链路是：
**理解 -> 规划 -> 调用工具 -> 生成回复**
Agent 先统一解析不同模态的信息，再做任务拆解规划，按需调度能力组件：图像理解(nlp)、文生图、ASR语音转文字、
文档OCR、联网搜索等工具
最后输出也支持多形态，既能返回文本、图片，也能输出语音、文件图表等
亮点在于它不是简单的串模型，而是把多模态感知、工具调用、任务编排封装成一个智能体，能承接跨模态的复杂业务场景，
比如看图后按指令画图、语音提问后返回图文报告，适配很多端侧、智能助手场景

## 编辑图片多模态Agent 业务链路

用户上传原图 + 编辑指令后，先把原图存到阿里云OSS，拿到资源URL，避免大图直接传给大模型(带宽、成本、上下文控制)
接着Agent 携带Oss 服务器的图片地址和用户指令调用多模态大模型，由模型完成图片编辑，拿到结果后，Agent再把新图写到OSS，最后把成品图的URL返回给用户

OSS 做对象存储解耦，Agent 承担调度、资源管理的中间层角色，而不是单纯转发请求；
同时统一管理原图和产出图，方便后续溯源、缓存和复用，适合图片生成、修图这类生产型业务
