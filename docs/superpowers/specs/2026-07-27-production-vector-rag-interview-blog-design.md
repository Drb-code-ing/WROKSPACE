# 生产级向量检索与 RAG 面试博客设计

日期：2026-07-27

## 目标

新增 `v054` 中文技术博客，面向 RAG / AI Agent 后端岗位面试。文章基于 Milvus、Zilliz Cloud、Embedding 写入、向量检索和 RAG 问答的实际学习项目，扩展为可用于生产实践与面试表达的知识体系。

## 范围

覆盖：

- 向量数据库在 RAG 中的职责，以及与关系型数据库、全文检索的边界。
- 文档处理、切块、Embedding、写入、建索引、加载、查询、重排、生成的端到端数据流。
- Milvus collection schema：主键、FloatVector、文本与元数据字段，向量维度和模型版本的绑定关系。
- COSINE、IP、L2 的选择；FLAT、IVF_FLAT、HNSW 的原理与权衡。
- `nlist`、`nprobe`、`M`、`efConstruction`、`ef` 等检索参数的作用与调优方向。
- Top-K、metadata filter、混合检索、重排、阈值和低置信度拒答。
- Recall@K、MRR、NDCG、延迟、成本等评估与可观测性指标。
- 写入/flush/索引/load 生命周期、更新删除、容量规划和托管/自建取舍。
- 高密度面试问答与一个日记语义检索 RAG 案例。

不覆盖：

- 具体云厂商控制台操作。
- 向量模型训练与微调。
- 完整分布式部署命令或 Kubernetes 运维教程。
- 无关的通用 LLM 基础知识。

## 读者与写作风格

读者具备基础后端或 RAG 开发经验。文章采用“概念 → 原理 → 生产决策 → 面试回答”的结构；所有描述使用明确技术术语，不使用“来自某篇笔记”等模糊来源表达。

## 文章结构

1. 问题定义：为何 RAG 需要向量检索层。
2. 端到端架构与请求链路。
3. 数据建模与 Embedding 生命周期。
4. 距离度量和 ANN 索引原理。
5. 生产检索与召回质量治理。
6. 可观测性、可靠性、扩缩容和成本。
7. 高频面试题与答题框架。
8. 日记检索案例及从 Demo 到生产的缺口。

## 验收标准

- 文章能清晰解释 schema、metric、index、召回、重排和质量评估之间的关系。
- 有可直接复述的面试答案，而非只有名词列表。
- 清楚标注近似最近邻检索的速度/召回率权衡，不将距离分数误说为跨模型可比较的百分比。
- 博客索引与当前版本指针同步更新。
- 不纳入工作区已有的无关 package 或未跟踪文件。
