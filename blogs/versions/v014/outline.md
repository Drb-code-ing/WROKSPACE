# v014 大纲

## 标题
从代码到智能体：一个 AI Native 开发者的 Coze 平台初体验

## 结构

### 引言
- v013 学了前端规范化（语义化标签、BEM、CSS Reset）
- v014 切换到 AI 应用层：用 Coze 平台零代码搭建智能体
- 核心观点：AI 开发不只是写代码调 API，还可以用可视化平台构建智能体
- Coze 是字节跳动推出的 AI Agent 开发平台，零代码、可视化

### 一、AI Agent：从被动响应到自主执行
- AI 智能体定义：能自主感知环境、规划决策并独立完成多任务的自主型人工智能程序
- 核心组件：
  - 大脑：大模型（负责思考和决策）
  - 手和脚：执行任务（自动化）
- 与传统 AI 的区别：不只是问答，还能主动执行任务
- 呼应 v011：Prompt Engineering 是 Agent 的基础

### 二、知识库：给 AI 装上"外部记忆"
- 问题：LLM 的局限性
  - 训练数据有截止日期，最新数据没有
  - 个人、企业私有数据没有
- 解决方案：知识库
  - 结构化存储领域知识
  - 供 AI 查询调取以精准答疑推理
- 知识库类型：
  - 文本上传（text、word、pdf）
  - 表格（excel）
  - 在线数据
  - 数据库
  - 飞书等企业知识库
- 关键点：知识库需要清洗、鉴别、整理、存储

### 三、Coze 平台：零代码搭建智能体
- Coze 简介：AI Agent 开发平台
- 创建流程：
  1. 新建 Coze agent
  2. 配置 Prompt（人设 + 功能描述）
  3. 添加知识库
  4. 测试和发布
- Prompt 规则：
  - 给一个人设（智能体的个人特征、行为和目标）
  - 告诉他能干什么，不能干什么（清晰的边界）
- 示例 Prompt：
  - "你是一个智能客服机器人，你收到用户的提问后，需要调用知识库去查询内容。将查询到的信息返回给用户。"

### 四、Prompt 在 NLP 中的应用扩展
- 自然语言处理（NLP）的多模态发展
- 从文本生成到图像生成
  - 多模态能力
  - OpenAI SDK 换成了 fetch 请求
- 技术细节：
  - 本质都是向 LLM 远程服务器发送 HTTP 请求
  - URL 地址
  - 配置请求对象：
    - method: POST（比 GET 更安全）
    - headers: 请求头指定 apiKey（Authorization 权限）
    - body: 请求体（messages、多张图片和文字指令）
