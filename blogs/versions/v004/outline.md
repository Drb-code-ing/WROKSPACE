# v004 大纲

## 标题
从 VS Code 到命令行：一个 AI Native 开发者的 Claude Code 工作流进化

## 结构

### 引言
- 接 v003：从 AI Coding Agent 到真正融入开发工作流
- 提出新问题：VS Code 插件很好，但能不能更进一步？
- CLI 工具给出了答案

### 一、从插件到 CLI：更深的集成
- v003 VS Code 插件：在编辑器内使用 AI Agent
- CLI 更进一步：在任何终端中使用
  - npm 全局安装
  - 淘宝镜像解决国内网络问题
  - `claude` 命令直达
- 意义：不依赖 IDE，可以在任何工作流中使用

### 二、信任与权限：AI Agent 的安全哲学
- 首次运行：文件夹信任询问
- 类比：给程序员办公室门禁
- Anthropic 的"最小权限 + 安全边界"设计理念
- 呼应 v003 单独窗口打开项目——给 Agent 边界感

### 三、/plan 模式：先规划再执行
- 传统工作流：直接写 prompt → 执行
- /plan 模式：先规划再执行
  - CLI 提问 → 生成计划 → 确认后执行
  - 新手友好：降低领域知识门槛
- 思考 vs 执行的分工
- 本质是 prompt 设计的结构化和流程化

### 四、Vibe Coding 再思考
- 不要直接丢任务给 LLM
- 先思考：五个构建块
- LLM 擅长执行精准详细的任务
  - 呼应 v002 "代码向后，业务向前"
  - 呼应 v003 六要素框架
- Prompt 设计仍然是核心竞争力

### 五、用 CLAUDE.md 管理项目
- /init 初始化项目 → AI 自动分析生成文档
- 已有项目维护：CLAUDE.md 是给 AI 的说明书
- 实战：JavaScript 鼓点模拟器
  - AI 分析项目 → CLAUDE.md 文档
  - 架构说明、按键映射、文件结构
  - 下次 AI 进入项目马上理解上下文

### 结语
- 四篇文章的就是一条能力进化路径
  - v001：知道 AI 能做什么
  - v002：知道怎么写指令
  - v003：知道怎么用 Agent 做项目
  - v004：知道怎么让 Agent 融入日常开发
- Be AI Native 是一步步走出来的实践路径
