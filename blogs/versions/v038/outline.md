# v038 大纲

## 标题
从幻觉到检索增强：RAG 向量化语义搜索的工程启蒙

## 主题
第三十四天学习——从 LLM 幻觉的本质出发，理解 RAG（检索增强生成）的核心原理：文档切分、向量化、语义搜索与向量数据库，并通过 LangChain 代码实践把文档构建为可检索的知识库。

## 核心线索
v037 构建了 Agent 的上下文与工具调用体系，v038 回到一个更根本的问题：当模型"不知道"时，如何通过检索外部知识来增强它？答案是用向量化语义搜索把相关文档片段注入 Prompt。

## 章节结构

1. **引言** — 从"Agent 能做什么"推进到"Agent 不知道时怎么办"
2. **一、LLM 幻觉的本质** — 训练数据集的边界，大模型不会说"不知道"
3. **二、RAG 核心原理** — 检索→增强→生成的三步管线，去知识库查→放进 Prompt→让模型回答
4. **三、从关键词到向量：语义搜索的核心** — 文本匹配的局限，多维向量表达语义，余弦相似度
5. **四、嵌入模型与向量数据库** — embedding model 的作用，文档切分策略，向量存储与持久化
6. **五、代码实践：hello-rag.mjs** — LangChain Document 构建、OpenAIEmbeddings 配置、metadata 设计
7. **六、RAG 与 MCP Resource 的上下文拼图** — 两种向模型注入知识的方式：静态 Resource 直接注入 vs 大规模文档 RAG 检索
8. **结语** — 从理解幻觉到掌握 RAG，第三十四天补齐了 Agent 知识注入的最后一块拼图

## 核心代码

- hello-rag.mjs：LangChain ChatOpenAI + OpenAIEmbeddings + Document 文档数组构建
- readme.md：RAG 概念笔记，涵盖幻觉成因、向量语义搜索、嵌入模型与向量数据库

## 面试要点

- LLM 幻觉的成因与 RAG 的解决思路
- 关键词搜索 vs 向量语义搜索的区别与适用场景
- 嵌入模型（embedding model）的作用原理
- 余弦相似度在语义检索中的应用
- 文档切分（chunking）策略及其对检索质量的影响
- RAG 与 MCP Resource 直接注入的适用边界

## 情感线
从面对模型"胡说八道"的无力感，到掌握一套可工程化的知识检索方案——RAG 不只是技术方案，更是对 AI 能力边界的清醒认知。
